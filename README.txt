Shop Brand Kit
17 November 2026

Open Shop-brand-UI-UX-guide.html in a browser for the complete colour and UX guide. It contains embedded images and needs no network connection. Click a swatch to copy its hex code when browser permissions allow.

Shop-logo.png is the transparent raster logo (2172x724). Shop-review-UI-concept.png is an illustrative static interface concept. Shop-tokens.css and Shop-tokens.json are editable design handoff files. The UI illustration is not a working application or measured deployment. Logo vector masters, reversed artwork and an app-icon master are not included.

Image generation prompts and method are recorded in Shop-generation-prompts.txt. Palette contrast checks are token-level calculations; the finished product still needs accessibility and usability verification.
